# Portfolio Website for Aryan Thakur

## Overview

This is a clean, minimal portfolio website for Aryan Thakur, a B.Tech ECE student specializing in AI/ML and LLM development. The website showcases professional projects, achievements, skills, and contact information using a simple, fast-loading approach.

## System Architecture

### Simple Stack Architecture
- **Technology**: Vanilla HTML, CSS, and JavaScript
- **Styling**: Custom CSS with Inter font family and dark theme
- **Design**: Inspired by amritwt.me with clean, minimal aesthetic
- **Deployment**: GitHub Pages ready with single HTML file
- **Performance**: No build process, instant loading, minimal dependencies

## Key Components

### Website Sections
1. **Header**: Profile image, name, title, and availability status
2. **Navigation**: Simple horizontal navigation with smooth scrolling
3. **About**: Educational background and professional focus
4. **Education**: Academic credentials and timeline
5. **Projects**: Showcase of major projects with award badges and tech stacks
6. **Skills**: Categorized technical skills (AI/ML, Languages, Frontend, Backend)
7. **Contact**: Email and GitHub links with clean styling

### Design Features
- **Dark Theme**: Deep black background (#0a0a0a) with subtle borders
- **Typography**: Inter font family for clean readability
- **Responsive**: Mobile-first design with flexible layouts
- **Smooth Scrolling**: JavaScript-powered navigation highlighting
- **Hover Effects**: Subtle animations on interactive elements

## Deployment Strategy

### GitHub Pages Setup
- **File Location**: Single HTML file in `docs/index.html`
- **Configuration**: Repository Settings → Pages → Deploy from branch → main → /docs folder
- **URL**: `https://aryan2302.github.io/Portfolio`
- **Requirements**: No build process, instant deployment

### Performance Optimizations
- **Single File**: Complete website in one HTML file for fast loading
- **External Fonts**: Google Fonts for Inter typography
- **Minimal JavaScript**: Only navigation highlighting functionality
- **Image Optimization**: Profile photo served from GitHub repository
